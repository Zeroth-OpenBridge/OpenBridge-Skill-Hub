# Skill Hub

Skill development repository for Zeroth Bridge (小桥). It provides a Python SDK, APIs, skill templates, action chains, and official examples so developers can write, reuse, and deploy robot skills.

| Resource | Repository |
| --- | --- |
| Product introduction | [openbridge](https://github.com/Zeroth-OpenBridge/openbridge) |
| Connect robot and hardware | [Robot Hub](https://github.com/Zeroth-OpenBridge/OpenBridge-Robot-Hub) |
| Simulation and verification | [Simulation Hub](https://github.com/Zeroth-OpenBridge/OpenBridge-Simulation-Hub) |
